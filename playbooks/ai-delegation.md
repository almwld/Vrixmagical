# Playbook: unified AI delegation

## Goal
Use one orchestrator, reusable skills/playbooks and durable memory.

## Steps
1. Read root AI_TEAM and current handoff.
2. Define objective, non-goals, branch and acceptance gates.
3. Select one writer; choose one playbook and minimal supporting skills.
4. Delegate specialist review only when useful; give a complete handoff contract.
5. Keep reviewers read-only and bounded to one consultation plus one rebuttal.
6. Verify results independently and report evidence, not agent confidence alone.
7. Update PROJECT_STATE, decisions and current handoff; validate registry.

## Acceptance
One active writer per branch, registry validator passes, current handoff is accurate, no secrets or raw chain-of-thought are stored.
