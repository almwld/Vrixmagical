# VRIX durable AI memory

This folder is the shared handoff record for the entire repository. Read `../AI_TEAM.md` first.

| File | Purpose |
|---|---|
| `PROJECT_STATE.md` | Current verified project state and open acceptance gates |
| `decisions.md` | Durable decisions and rationale |
| `handoffs/current.md` | Active task, branch, owner, next action and acceptance |
| `registry.json` | Canonical index of skills and playbooks |

Memory is a compact operational record, not a transcript or hidden reasoning dump. Store only durable facts, decisions, paths, commit/PR identifiers, test evidence and risks. Never store credentials, tokens, private data or unredacted logs. Update existing state when it changes; do not leave contradictory status entries.
